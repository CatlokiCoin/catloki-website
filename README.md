# CATLOKI website

Static site for CATLOKI (CLOKI), a community meme coin on Solana. Plain HTML, CSS and JS: no dependencies and no build step.

## Run locally
    python3 -m http.server 8080 --bind 127.0.0.1
    # open http://127.0.0.1:8080/
